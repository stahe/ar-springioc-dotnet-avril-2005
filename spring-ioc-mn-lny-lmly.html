    5. Spring IoC من الناحية العملية

    سنناقش الآن، من خلال أمثلة، تطبيق ما رأيناه سابقًا عمليًّا.

    5.1. المثال 1

    الفئة [Personne.vb] هي كما يلي:

    Namespace istia.st.springioc.demos
    Public Class Personne

         ' الحقول الخاصة
        Private _nom As String
        Private _age As Integer

         ' منشئ افتراضي
        Public Sub New()
        End Sub

         ' الخصائص المرتبطة بالحقول الخاصة
        Public Property nom() As String
            Get
                Return _nom
            End Get
            Set(ByVal Value As String)
                _nom = Value
            End Set
        End Property

        Public Property age() As Integer
            Get
                Return _age
            End Get
            Set(ByVal Value As Integer)
                _age = Value
            End Set
        End Property

         ' سلسلة الهوية
        Public Overrides Function tostring() As String
            Return String.Format("[{0},{1}]", nom, age)
        End Function

         ' طريقة init
        Public Sub init()
            Console.WriteLine("init personne {0}", Me.ToString)
        End Sub

         ' طريقة الإغلاق
        Public Sub close()
            Console.WriteLine("destroy personne {0}", Me.ToString)
        End Sub

    End Class
End Namespace

    تحتوي الفئة على:

    • حقلين خاصين هما «الاسم» و«العمر» يمكن الوصول إليهما عبر خصائص
    • طريقة toString لاسترداد قيمة الكائن [Personne] في شكل سلسلة أحرف
    • طريقة init التي سيستدعيها Spring عند إنشاء الكائن، وطريقة close التي سيستدعيها عند تدمير الكائن

    لإنشاء كائنات من النوع [Personne]، سنستخدم ملف Spring [spring-config-1.xml] التالي:

    <?xml version="1.0" encoding="iso-8859-1" ?>
<!DOCTYPE objects PUBLIC "-//SPRING//DTD OBJECT//EN"
"http://www.springframework.net/dtd/spring-objects.dtd">

<objects>
    <object id="personne1" type="istia.st.springioc.demos.Personne, demo1" init-method="init"
        destroy-method="close">
        <property name="nom">
            <value>Simon</value>
        </property>
        <property name="age">
            <value>40</value>
        </property>
    </object>
    <object id="personne2" type="istia.st.springioc.demos.Personne, demo1" init-method="init"
        destroy-method="close">
        <property name="nom">
            <value>Brigitte</value>
        </property>
        <property name="age">
            <value>20</value>
        </property>
    </object>
</objects>

    يُعرّف هذا الملف

    • يحدد كائنين للمفاتيح "personne1" و"personne2" على التوالي من النوع [Personne]
    • ويقوم بتهيئة خصائص [nom, age] لكل شخص
    • ويحدد الطرق التي يجب استدعاؤها عند الإنشاء الأولي للكائن [init-method] وعند إتلاف الكائن [destroy-method]

    لإجراء اختباراتنا، سنستخدم فئات اختبار NUnit. وستكون الفئة الأولى كما يلي:

    Imports System
Imports Spring.Objects.Factory.Xml
Imports System.IO
Imports NUnit.Framework
Imports istia.st.springioc.demos

Namespace istia.st.springioc.tests

    <TestFixture()> _
    Public Class NunitTestSpringIocDemo1
         ' الكائن المراد اختباره
        Private factory As XmlObjectFactory

        <SetUp()> _
        Public Sub init()
             ' يتم إنشاء مثيل من المصنع
            factory = New XmlObjectFactory(New FileStream("spring-config-1.xml", FileMode.Open))
             ' السجل
            Console.WriteLine("setup test")
        End Sub

        <Test()> _
        Public Sub demo()
             ' استرداد الكائنات [Personne] من ملف Spring باستخدام مفاتيحها
            Dim personne1 As Personne = CType(factory.GetObject("personne1"), Personne)
            Console.WriteLine("personne1=" + personne1.ToString())
            Dim personne2 As Personne = CType(factory.GetObject("personne2"), Personne)
            Console.WriteLine("personne2=" + personne2.ToString())
            personne2 = CType(factory.GetObject("personne2"), Personne)
            Console.WriteLine("personne2=" + personne2.ToString())
        End Sub

        <TearDown()> _
        Public Sub destroy()
             ' يتم تدمير الكائنات الفردية
            factory.Dispose()
             ' تحرير مورد المصنع
            factory = Nothing
             ' المتابعة
            Console.WriteLine("teardown test")
        End Sub

    End Class
End Namespace

    تعليقات:

    • للحصول على الكائنات المُعرَّفة في الملف [spring-config-1.xml]، نستخدم كائنًا من النوع [XmlObjectFactory]. وهناك أنواع أخرى من «المصانع» التي تتيح الوصول إلى الكائنات الفردية في ملف التكوين. يتم الحصول على الكائن [XmlObjectFactory] في طريقة السمة [SetUp] الخاصة بفئة الاختبار ويتم تخزينه في متغير خاص. تجدر الإشارة إلى أن الطريقة المزودة بالسمة <Setup()> يتم تنفيذها قبل كل اختبار.
    • سيتم وضع الملف [spring-config-1.xml] في المجلد [bin] الخاص بالتطبيق
    • يمكن لـ Spring استخدام ملفات التكوين ذات التنسيقات المختلفة. يتيح الكائن [XmlObjectFactory] تحليل ملف تكوين بتنسيق XML.
    • يؤدي تشغيل ملف Spring إلى إنتاج كائن من النوع [XmlObjectFactory]، وهو هنا كائن المصنع. باستخدام هذا الكائن، يمكن الحصول على كائن فريد (singleton) محدد بالمفتاح C، عن طريق factory.getObject(C).
    • تقوم الطريقة [demo] باستدعاء وعرض قيمة الكائنات الفردية ذات المفتاحين "personne1" و"personne2".

    تعليقات:

    • السطر 2: يبدأ الاختبار بتنفيذ طريقة السمة <Setup()>
    • السطر 3: العملية 
                Dim personne1 As Personne = CType(factory.GetObject("personne1"), Personne)

    أجبرت على إنشاء البين [personne1]. ونظرًا لأننا كتبنا [init-method="init"] في تعريف الكائن الفردي [personne1]، فقد تم تنفيذ الأسلوب [init] الخاص بالكائن [Personne] الذي تم إنشاؤه. ويتم عرض الرسالة المقابلة.

    init personne [Simon,40]
    • السطر 4: العملية 
                Console.WriteLine("personne1=" + personne1.ToString())

    أدت إلى عرض قيمة الكائن [Personne] الذي تم إنشاؤه.

    personne1=[Simon,40]
    • السطران 5-6: تتكرر نفس الظاهرة بالنسبة لـ bean المفتاح [personne2].
    init personne [Brigitte,20]
personne2=[Brigitte,20]
    • السطر 7: العملية الأخيرة 
    personne2 = CType(factory.GetObject("personne2"), Personne)
Console.WriteLine("personne2=" + personne2.ToString())

    لم تسفر إلا عن سطر واحد معروض:

    personne2=[Brigitte,20]

    وبالتالي، لم تؤدِ إلى إنشاء كائن جديد من النوع [Personne]. لو كان الأمر كذلك، لكان قد تم عرض طريقة [init]، وهو ما لم يحدث هنا. هذا هو مبدأ الكائن الفريد (singleton). لا يقوم Spring، بشكل افتراضي، بإنشاء سوى نسخة واحدة من الكائنات (beans) الموجودة في ملف التكوين الخاص به. وهو عبارة عن خدمة مرجعية للكائنات. إذا طُلب منه مرجع كائن لم يتم إنشاؤه بعد، فإنه يقوم بإنشائه ويقدم مرجعًا له. أما إذا كان الكائن قد تم إنشاؤه بالفعل، فإن Spring يكتفي بتقديم مرجع له.

    • الأسطر 8-10: يتم تنفيذ طريقة السمة <TearDown()> (السطر 10). وفي داخلها، تتم العملية
                 ' يتم تدمير الكائنات الفردية
            factory.Dispose()

    إتلاف الكائنات الفردية التي أنشأها Spring. ويؤدي ذلك إلى تنفيذ طريقة كل منها [close] لأننا كتبنا، في ملف التكوين، لكل منها: "destroy-method=close". وهذا ما تشير إليه العروض التالية:

    destroy personne [Simon,40]
destroy personne [Brigitte,20]

    وبما أننا اكتسبنا الآن أساسيات تكوين Spring، فسنكون من الآن فصاعدًا أسرع قليلاً في شرحنا.

    5.2. المثال 2

    لننظر إلى الفئة الجديدة التالية [Voiture]:

    Imports istia.st.springioc.demos

Namespace istia.st.springioc.demos

    Public Class Voiture
         ' الحقول الخاصة
        Private _marque As String
        Private _type As String
        Private _propriétaire As Personne

         ' الخصائص العامة
        Public Property marque() As String
            Get
                Return _marque
            End Get
            Set(ByVal Value As String)
                _marque = Value
            End Set
        End Property

        Public Property type() As String
            Get
                Return _type
            End Get
            Set(ByVal Value As String)
                _type = Value
            End Set
        End Property

        Public Property propriétaire() As Personne
            Get
                Return _propriétaire
            End Get
            Set(ByVal Value As Personne)
                _propriétaire = Value
            End Set
        End Property

         ' منشئ افتراضي
        Public Sub New()

        End Sub

         ' منشئ بثلاثة معلمات
        Public Sub New(ByVal marque As String, ByVal type As String, ByVal propriétaire As Personne)
             ' يتم تهيئة الحقول الخاصة عبر خصائصها المرتبطة
            With Me
                .marque = marque
                .type = type
                .propriétaire = propriétaire
            End With
        End Sub

         ' سلسلة تعريف كائن «السيارة»
        Public Overrides Function tostring() As String
            Return String.Format("[{0},{1},{2}]", marque, type, propriétaire.ToString)
        End Function

         ' طريقتا init وdestroy
        Public Sub init()
            Console.WriteLine("init voiture {0}", Me.ToString)
        End Sub

        Public Sub destroy()
            Console.WriteLine("destroy voiture {0}", Me.ToString)
        End Sub

    End Class
End Namespace

    تحتوي الفئة على:

    • ثلاثة حقول خاصة هي _type و _marque و _propriétaire. يمكن تهيئة هذه الحقول وقراءتها من خلال الخصائص العامة. كما يمكن تهيئتها باستخدام منشئ Voiture(String, String, Personne). تحتوي الفئة أيضًا على مُنشئ بدون معلمات يسمح أولاً بإنشاء كائن [Voiture] غير مُهيأ، ثم تهيئته لاحقًا عبر خصائصه العامة.
    • طريقة toString لاسترداد قيمة الكائن [Voiture] في شكل سلسلة أحرف
    • طريقة init التي سيستدعيها Spring مباشرة بعد إنشاء الكائن، وطريقة destroy التي سيستدعيها عند تدمير الكائن

    لإنشاء كائنات من النوع [Voiture]، سنستخدم ملف Spring [spring-config-2.xml] التالي:

    <?xml version="1.0" encoding="iso-8859-1" ?>
<!DOCTYPE objects PUBLIC "-//SPRING//DTD OBJECT//EN"
"http://www.springframework.net/dtd/spring-objects.dtd">
<objects>
     <!-- الأشخاص -->
    <object id="personne1" type="istia.st.springioc.demos.Personne, demo1" init-method="init"
        destroy-method="close">
        <property name="nom">
            <value>Simon</value>
        </property>
        <property name="age">
            <value>40</value>
        </property>
    </object>
    <object id="personne2" type="istia.st.springioc.demos.Personne, demo1" init-method="init"
        destroy-method="close">
        <property name="nom">
            <value>Brigitte</value>
        </property>
        <property name="age">
            <value>20</value>
        </property>
    </object>
     <!-- سيارة -->
    <object id="voiture1" type="istia.st.springioc.demos.Voiture, demo1" init-method="init"
        destroy-method="destroy">
        <constructor-arg index="0">
            <value>Peugeot</value>
        </constructor-arg>
        <constructor-arg index="1">
            <value>307</value>
        </constructor-arg>
        <constructor-arg index="2">
            <ref object="personne2"/>
        </constructor-arg>
    </object>
</objects>

    يضيف هذا الملف إلى التعريفات السابقة كائن مفتاح "voiture1" من النوع [Voiture]. لتهيئة هذا الكائن، كان من الممكن كتابة:

        <object id="voiture1" type="istia.st.springioc.demos.Voiture, demo1" init-method="init"
        destroy-method="destroy">
        <constructor-arg index="0">
            <value>Peugeot</value>
        </constructor-arg>
        <constructor-arg index="1">
            <value>307</value>
        </constructor-arg>
        <constructor-arg index="2">
            <ref object="personne2"/>
        </constructor-arg>
    </object>

    بدلاً من اختيار هذه الطريقة التي سبق عرضها، اخترنا هنا استخدام منشئ Voiture(String, String, Personne) الخاص بالفئة. من ناحية أخرى، يحدد العنصر الفردي [voiture1] الطريقة التي يجب استدعاؤها عند الإنشاء الأولي للكائن [init-method] والطريقة التي يجب استدعاؤها عند تدمير الكائن [destroy-method].

    5.3. المثال 3

    نقوم بإدخال الفئة الجديدة [GroupePersonnes] التالية:

    Imports istia.st.springioc.demos

Namespace istia.st.springioc.demos

    Public Class GroupePersonnes
         ' الحقول الخاصة
        Private _membres() As Personne
        Private _groupesDeTravail As Hashtable

         ' الخصائص العامة
        Public Property membres() As Personne()
            Get
                Return _membres
            End Get
            Set(ByVal Value() As Personne)
                _membres = Value
            End Set
        End Property

        Public Property groupesDeTravail() As Hashtable
            Get
                Return _groupesDeTravail
            End Get
            Set(ByVal Value As Hashtable)
                _groupesDeTravail = Value
            End Set
        End Property

         ' منشئ افتراضي
        Public Sub New()

        End Sub

         ' سلسلة هوية الكائن GroupeDePersonnes
        Public Overrides Function tostring() As String
             ' يتم تصفح قائمة أعضاء المجموعة
            Dim identité As String = "[membres=("
            Dim i As Integer
            For i = 0 To membres.Length - 2
                identité += membres(i).ToString + ","
            Next
            identité += membres(i).ToString + "), groupes de travail=("
             ' يتم تصفح قاموس مجموعات العمل
            Dim clés As IEnumerator = groupesDeTravail.Keys.GetEnumerator
            Dim clé As Object
            While clés.MoveNext
                clé = clés.Current
                identité += String.Format("[{0},{1}] ", clé, groupesDeTravail(clé))
            End While
             ' إرجاع النتيجة
            Return identité + "]"
        End Function

         ' طرق init-destroy
        Public Sub init()
            Console.WriteLine("init GroupeDePersonnes {0}", Me.ToString)
        End Sub

        Public Sub destroy()
            Console.WriteLine("destroy GroupeDePersonnes {0}", Me.ToString)
        End Sub

    End Class
End Namespace

    عضواها الخاصان هما:

    _membres: جدول بأسماء أعضاء المجموعة

    _groupesDeTravail: قاموس يربط شخصًا بمجموعة عمل

    يتم إتاحة الوصول إلى هذه العناصر الخاصة عبر خصائص عامة. نهدف هنا إلى توضيح كيفية قيام Spring بتهيئة الكائنات المعقدة، مثل الكائنات التي تحتوي على حقول من نوع المصفوفة أو القاموس.

    سيكون ملف تكوين Spring [spring-config-3.xml] كما يلي:

"http://www.springframework.net/dtd/spring-objects.dtd">

        destroy-method="close">
        <property name="nom">
            <value>Simon</value>
        </property>
        <property name="age">
            <value>40</value>
